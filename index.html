Estimated using 5 signals · 100% local analysis

Each sentence is scored 0 to 100 on five weighted signals. Names, numbers, abbreviations, headings and very short sentences are handled separately. Syllable counts, clause counts and passive-voice flags come from word patterns, not a grammar parse, so treat scores as a guide.

How the scoring changed

  • v1 Flesch Reading Ease for the chapter, with the longest sentences listed by grade level.
  • v2 Five-signal model: lexical, sentence complexity, readability formulas, structure and relative difficulty. Names, numbers and abbreviations ignored in vocabulary scoring. Mostly-dialogue sentences weighted at 70%.
  • v3 Every eligible sentence gets the full analysis in one pass, so the Easy / Moderate / Difficult counts, the map and the top 5 agree. Removed the misleading "two-stage" wording.
  • v4 Names and abbreviations removed from the readability-formula signal. Top 5 requires a minimum score of 25. Short technical sentences (6+ words) can now rank.
